# شناوي — مشروع تطبيق أندرويد (Capacitor)

مشروع Android جاهز لبناء تطبيق **شناوي** كملف APK. الموقع كامل جوه مجلد `www/` والأيقونات والاسم جاهزين.

## الطريقة الأولى: البناء بـ Android Studio (الموصى بها)

### الخطوة ١: ثبّت Android Studio
- نزّله مجانًا من الموقع الرسمي: https://developer.android.com/studio
- أثناء التثبيت، تأكد إن **Android SDK** و**Android SDK Platform** اتثبتوا (بييجوا مع البرنامج افتراضيًا).
- أول مرة تفتحه، سيخلّص تحميل المكونات — خلّيه يخلص.

### الخطوة ٢: افتح المشروع
- افتح Android Studio → **Open** → اختار مجلد `android` الموجود جوه هذا الملف.
- استنى الـ **Gradle Sync** يخلص (أول مرة بياخد ٥-١٠ دقايق).

### الخطوة ٣: ابنِ الـ APK
- من القائمة: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
- استنى البناء يخلص (أول مرة بياخد دقايق).

### الخطوة ٤: خد الملف وركّبه
- الـ APK هيظهر هنا:
  `android/app/build/outputs/apk/debug/app-debug.apk`
- انقل الملف لموبايلك (كابل أو واتساب أو Google Drive) وافتحه على الموبايل
- الموبايل هيطلب منك السماح بالتثبيت من مصادر خارجية → **السماح** → ثبّت ✅

> ملاحظة: ملف `app-debug.apk` يصلح للتجربة. للنشر على Google Play أو التوزيع العام، اعمل **Build → Generate Signed Bundle / APK** ووقّع بموقعك.

## الطريقة الثانية: من غير أي برامج (الأسهل)

موقعك الأصلي شغال على https://shenawy.site.accio.ai وبيشتغل كـ PWA (تطبيق ويب).

1. افتح https://www.pwabuilder.com
2. اكتب رابط موقعك: `https://shenawy.site.accio.ai` → **Start**
3. اضغط **Package for stores** → **Android** → **Generate package**
4. نزّل الـ APK الناتج وركّبه على موبايلك

> بيشتغل كده بنفس طريقة الموقع (WebView)، وبيحتاج إنترنت لبعض المزايا.

## لو عايز تعدّل في المشروع بعد كده

```bash
# 1) لو عدّلت في الموقع الأصلي (yawmi) ، أعيد بناء النسخة الجديدة وانسخها:
cp -r ../yawmi/dist/* www/

# 2) مزامنة التغييرات مع مشروع أندرويد:
npx cap sync android

# 3) افتح في Android Studio وابني تاني
npx cap open android
```
